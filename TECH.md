# Tech Stack

## Frontend

| Параметр        | Значення         |
| --------------- | ---------------- |
| Фреймворк       | React            |
| Стан застосунку | Zustand          |
| Маршрутизація   | React Router DOM |
| Стилізація      | Tailwind         |
| Збірка          | Vite             |

Чому обрали:

- **React**: Світовий стандарт та один із найпопулярніших інструментів для розробки сучасних SPA-застосунків на ринку праці. Ідеально підходить для Kanban-систем завдяки компонентній структурі, реактивності та зручному оновленню стану карток, колонок і модалок.
- **Zustand**: Легковаговий, гнучкий та продуктивний стейт-менеджер з мінімальною кількістю шаблонного коду. Відмінна та сучасна альтернатива Redux для управління глобальним станом (дошки, картки, теми, модальні вікна).
- **React Router DOM**: Індустріальний стандарт для декларативної маршрутизації в React, що забезпечує чіткий розподіл сторінок (`/welcome`, `/auth`, `/home/:boardId`).
- **Tailwind CSS**: Передовий утилітарний CSS-фреймворк, який дозволяє швидко будувати сучасні, гнучкі та адаптивні інтерфейси без громіздких стильових файлів, а також легко реалізовувати підтримку кількох тем (Light, Dark, Violet).
- **Vite**: Сучасний, надшвидкий інструмент збірки та розробки (з HMR), який значно прискорює процес розробки та збірки проєкту у порівнянні з класичними Webpack/CRA.

## Backend

| Параметр         | Значення   |
| ---------------- | ---------- |
| Мова             | Node.js    |
| Фреймворк        | Nest       |
| База даних       | PostgreSQL |
| ORM / драйвер    | TypeORM    |
| Автентифікація   | JWT        |
| Документація API | Swagger    |

Чому обрали:

- **Node.js & NestJS**: NestJS — один із провідних enterprise-фреймворків для Node.js на ринку праці. Він надає чітку модульну архітектуру, строгу типізацію (TypeScript) та паттерн Dependency Injection, що спрощує командну розробку, масштабування та підтримку проєкту.
- **PostgreSQL**: Надійна та високопродуктивна реляційна база даних, що є стандартом індустрії. Ідеально підходить для збереження структурованих зв'язаних даних (користувачі -> дошки -> колонки -> картки).
- **TypeORM**: Популярна ORM для TypeScript та Node.js, яка спрощує взаємодію з базою даних, міграції та моделювання реляційних сутностей через класи та декоратори.
- **JWT (JSON Web Tokens)**: Стандартне та безпечне рішення для stateless-автентифікації користувачів у REST API.
- **Swagger**: Індустріальний стандарт автоматичної генерації інтерактивної документації REST API, що відповідає вимогам ТЗ та гарантує зручну інтеграцію фронтенду з бекендом.

## Знання команди

Що знаємо добре:

- **Мови та базові технології**: JavaScript (ES6+), HTML5, CSS3.
- **Backend fundamentals**: Node.js та Express.js (принципи побудови REST API, обробка запитів, middleware).
- **Бази даних & мережі**: Розуміння основ реляційних баз даних, HTTP-протоколу та REST-архітектури.
- **Менторство та експертиза**: Досвідчений Team Lead, який знає стек на високому рівні, координує архітектурні рішення та допомагає вирішувати складні технічні задачі.

Що вчимо по ходу:

- **React**: Компонентний підхід, хуки, робота з маршрутизацією (React Router) та управління станом через Zustand.
- **NestJS**: Модульна архітектура, Dependency Injection, декоратори, інтеграція з TypeORM та побудова enterprise бекенду.
- **TypeScript**: Робота зі строгою типізацією на фронтенді та бекенді.
- **Tailwind CSS**: Утилітарна стилізація та реалізація тем оформлення.

Як закриємо прогалини:

- **Університетські курси**: Проходження відповідних профільних курсів із React та NestJS в університеті.
- **Офіційна документація**: Систематичне вивчення документації React, NestJS, Zustand, TypeORM та Tailwind.
- **Відкриті ресурси**: Використання практичних гайдів, навчальних туторіалів та відкритих матеріалів.
